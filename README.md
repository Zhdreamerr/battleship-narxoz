# Морской бой — Narxoz Incubator 2026

Минималистичное веб-приложение классической игры «Морской бой», разработанное в рамках второго этапа отбора Narxoz Incubator 2026. 

## Особенности (Уровень «Средний» с элементами «Сильного»)
- **Игра против компьютера** с тремя уровнями сложности (Лёгкий, Средний, Сложный). На уровнях выше легкого компьютер добивает найденные корабли, а на сложном — ищет по «шахматке».
- **Сохранение состояния:** весь прогресс партии, расположение кораблей и текущий ход сохраняются в `LocalStorage`. При обновлении страницы игра продолжается с того же места.
- **Интерфейс:** строгий монохромный дизайн без отвлекающих элементов, адаптированный под мобильные устройства.
- Ручная (кликами) и автоматическая расстановка кораблей с проверкой на соприкосновение и пересечение.

## Технологии
- HTML5, CSS3, Vanilla JavaScript (без сторонних библиотек).
- Vibe Coding: логика и визуальная часть сгенерированы с использованием AI-инструментов.
