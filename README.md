# Operation: Battleship // Narxoz Incubator 2026

Классический «Морской бой», переосмысленный в эстетике хакерского терминала и SOC-дашборда. Проект разработан для второго этапа отбора в Narxoz Incubator 2026 и претендует на уровень реализации **«Великий»**.

## Ключевые особенности (Уровень «Великий»)
1. **Сетевая атака (Мультиплеер 1 на 1):** Полноценная онлайн-игра. Реализовано лобби со списком свободных серверов, подключение по ID комнаты и синхронизация ходов в реальном времени через Firebase Realtime Database.
2. **Глобальный рейтинг и Статистика:** Интеграция с Firebase Auth и Firestore. Профиль хранит винрейт и точность игрока, а глобальный лидерборд выводит топ-10 операторов.
3. **Тренер уязвимостей:** После окончания партии формируется лог-отчет с анализом точности стрельбы и тактическим советом для игрока.
4. **Бизнес-мышление (Монетизация):** Разработан прототип PRO-режима (ROOT ДОСТУП) с оформлением подписки для демонстрации развития продукта.

## Логика и Архитектура
- Строгое соблюдение правил: корабли не пересекаются, ход передается сопернику **только при промахе**.
- Single Page Application (SPA): переключение экранов и вкладок происходит мгновенно без перезагрузки страницы.
- ИИ (Локальный взлом): 3 уровня сложности. На уровне Hacker бот использует алгоритм поиска добивания и простреливает сетку «шахматкой».
- Vibe Coding: архитектура SPA и дизайн терминала генерировались с помощью AI-ассистентов, при этом интеграция баз данных и игровая математика контролировались и собирались вручную.

## Стек технологий
- Frontend: HTML5, CSS3, Vanilla JavaScript (без фреймворков).
- Backend (BaaS): Firebase SDK v9 (Auth, Firestore, Realtime Database).
